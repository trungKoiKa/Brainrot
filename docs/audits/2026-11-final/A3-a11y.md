Second Brain, production build on http://localhost:3100, demo account, 11/11/2026, branch `redesign-10-final` (HEAD 1b86a87).
Read-only: no repo edits. One reversible data action: on /tasks I completed one task and then undid it through the toast's "Hoàn tác" (3 times: light, dark, 375). The task ended restored and unchecked each time. I logged out briefly to audit /login, then logged back in.

## Method

- Scripts are in `scratchpad/final-audit/a3/` (reused from `scratchpad/a3/`, pointed at CDP port 9335). Raw JSON is in `*.json`. Scenario output is in `*.txt`.
- `audit.js` ran on 8 app routes (/today, /tasks, /goals week/month/year, /dashboard, /settings, /khong-co-trang) × 7 viewports: 1440×900 light and dark, 375×812 light and dark, 768×1024, 720×450 (≈200 % zoom), and 320×640 reflow. That is 56 runs. /login ran separately at 1440 light/dark, 375 light/dark and 320.
- `checks.mjs` drove a real keyboard through CDP `Input.dispatchKeyEvent`:
  - Tab-order focus-ring contrast, first 40 stops, 5 routes × 2 themes (`ring.txt`)
  - skip link and landmarks (`skip.txt`), mobile drawer (`drawer.txt`, `esc*.mjs`), Shift+Tab under the sticky header (`sticky.txt`)
  - charts (`charts.txt`), dropdown menu and popovers (`menu.txt`), Settings buttons with `<details>` opened (`settings.txt`)
  - toasts (`toast*.txt`), habit grid (`habit.mjs`)
- The token pairs measured live match `app/globals.css`: `--input-border` light #848a7f, dark #6f776c; `--ring` = `--primary` #b03a0a / #ff8a3d.
- Gotcha for anyone re-running this: Git Bash rewrites `/tasks` into a Windows path, so the first matrix run silently stayed on /today and /goals. The matrix was re-run with `MSYS_NO_PATHCONV=1`. Every JSON file records the URL it actually measured.
