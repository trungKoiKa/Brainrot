# A3 — Accessibility + responsive audit (WCAG 2.2 AA)

Second Brain, production build on http://localhost:3100, demo account, 10/11/2026.
Agent A3. Read-only: no repo edits, no data changes (menus and popovers opened and closed only).

## Method

- Injected audit script (`scratchpad/a3/audit.js`) on every route × {1440×900 light, 1440×900 dark, 375×812 mobile light/dark, 768×1024, 720×450 (≈200 % zoom of 1440)}: 42 runs, raw JSON in `scratchpad/a3/*.json`.
  - Contrast: every visible text node, colours from `getComputedStyle` resolved through canvas (handles oklab/oklch), alpha and ancestor opacity blended over the real stacked background. Placeholders via `::placeholder`. Non-text: control borders vs parent background. SVG `<text>` fill and chart shapes measured separately (`svg.js`).
  - Focus order (first 30 focusables), accessible-name approximation, landmarks, headings (incl. `role=heading aria-level`), live regions, aria state attributes, unhidden SVGs, target sizes with the 2.5.8 spacing test (24 px circle), overflow/clipping, sticky/fixed elements, running animations, `prefers-reduced-motion` rules in all stylesheets.
- Real keyboard via CDP `Input.dispatchKeyEvent` (`kb.mjs`): Tab sequences with focus-ring colour/contrast and `:focus-visible`, Enter/ArrowDown/Escape on the dropdown menu, both popovers, the inline "Dời" picker, and the mobile drawer (`dr.mjs`). Shift+Tab under the sticky header at 375 px (`ob.mjs`). Reflow at 320 px.
- /login and the error boundary were checked from source plus the existing screenshots. Their token pairs are the same as the app's.
- Caveats: the accessible-name check is a simplified version of accname, not a screen reader. The data changed under me (other agents renamed the profile and added tasks named "A2 …"), but that does not affect any finding. Native-checkbox focus rings use `outline: auto`. I report the computed outline colour, though Chromium may draw it two-tone.

## 4. Target size (2.5.8)

**No failures** once the spacing exception is applied, at 1440, 768, 720 and 375 px.
Under 24 px but passing by spacing or label: native task checkboxes 16×16 (wrapped in padded `label.-m-3.p-3`, effective target about 40 px); goal check box 20×20; "Thêm làm mục tiêu" text buttons 137×20; dashboard legend links 15 px tall; Settings "Đổi tên"/"Xóa" 20 px tall at ≥ md (`md:min-h-0` removes the 40 px mobile height); goal-panel and habit icon buttons 28 px at desktop (`size-10 md:size-7`); habit grid days exactly 24×24 at desktop and 32 px on mobile. Mobile sizing (`min-h-10`, `size-10`) is consistently applied. Desktop sizes sit at the threshold, so a redesign must not shrink them.

## 5. Responsive

- No horizontal page overflow at 320, 375, 768 or 720 px on any route (`scrollWidth == clientWidth`).
- The habit month table scrolls inside its own `overflow-x-auto` container (1324 px content in 333 px at 375) with a sticky first column. That is allowed for data tables. The scroller is not itself focusable, but its day buttons are.
- The sticky 48 px header on all sizes causes K1. The sidebar becomes a Sheet drawer below md (K2). Fixed desktop sidebar: OK.
- Clipped text: only intentional ellipsis truncation (S6) and sr-only text.

## 6. Motion

App code never handles `prefers-reduced-motion`: zero `motion-reduce:`/`motion-safe:` classes and no media query. The only reduced-motion rule in all loaded CSS is a library `.shimmer` rule.
Animating with no opt-out: Recharts mount animations for bars and areas (`isAnimationActive` default; only the sparkline line disables it, `dashboard-blocks.tsx:119`), tw-animate-css enter/exit on dropdowns, popovers, tooltips and the Sheet, sidebar width/left transitions (200 ms linear, `ui/sidebar.tsx:221,233`), `animate-pulse` skeletons (all page `loading`/Suspense fallbacks), and chevron rotations.
None of this fails AA (2.3.3 is AAA, and 2.2.2 is not triggered because everything stops within 5 s or is a loading indicator). It is a quality gap, and the redesign should add a global reduced-motion guard.

## 7. Language

- `<html lang="vi">` is correct. Document titles are set ("Đăng nhập · Second Brain", "Second Brain").
- English strings inside the Vietnamese page, with no `lang="en"` (3.1.2, low): nav labels "Dashboard / Today / Tasks / Goal" (`components/sidebar.tsx:30-33`), header label, "Deadline" (button `aria-label`), "Daily Log hôm nay", mobile Sheet accessible name **"Sidebar"** and description **"Displays the mobile sidebar."** (`ui/sidebar.tsx:199-200`), SidebarRail `aria-label`/`title` "Toggle Sidebar" (`ui/sidebar.tsx:287,290`), Sheet close sr-only "Close" (`ui/sheet.tsx:75`, hidden in the sidebar), and the SidebarTrigger fallback sr-only "Toggle Sidebar" (overridden by the Vietnamese `aria-label`). Vietnamese screen-reader voices will mispronounce these. Either translate them or mark them with `lang="en"`.

## What a redesign's component choices must guarantee

1. **Focus indicator**: a solid 2 px ring at ≥ 3:1 against both the control and the page in both themes (use `--primary` at full opacity, not `ring/50`), applied globally by `:focus-visible`, including native checkboxes and links. Menu and listbox items need a highlight state ≥ 3:1 (or an outline), not `surface-muted`.
2. **Control boundaries**: input, select, checkbox and toggle-cell borders ≥ 3:1 (a darker `--input` token distinct from the decorative `--line`).
3. **Status colours as text**: every tone used for text (warning, good, field colours, chart ticks) must have a text-safe variant ≥ 4.5:1 per theme. Never use opacity on muted text. Chart axis and legend text must come from tokens (verify the selector against the installed Recharts DOM).
4. **Overlays**: drawer, dialog and popover must close on Escape, return focus to the trigger, close on route change, expose `aria-expanded` and `aria-controls` on triggers, and carry a Vietnamese accessible name.
5. **Landmarks**: exactly one `<main>`, a `<header>` banner outside it, and the sidebar as `<nav>` with the account controls inside a landmark. Add a skip link to `#main`.
6. **Sticky chrome**: set `scroll-padding-top` (and bottom, if a bottom bar is added) to at least the header height.
7. **Charts**: decorative or aria-hidden charts must not be focusable (`accessibilityLayer={false}` / `tabIndex={-1}`). Every chart needs a text summary plus an equivalent link or table, and colour must never be the only carrier (field colours fail 3:1 in light).
8. **Targets**: keep ≥ 24×24 at desktop (prefer 32) and ≥ 40 on touch. Do not use `md:min-h-0` to shrink below 24.
9. **Motion**: a global `@media (prefers-reduced-motion: reduce)` that disables tw-animate enter/exit, sidebar transitions, pulse skeletons and Recharts animation (`isAnimationActive={!reduced}`).
10. **Language**: all UI strings in Vietnamese (including library defaults such as Sheet title, "Close" and "Toggle Sidebar"), or `lang="en"` on intentional English labels. Keep unique, contextual button names ("Đổi tên dự án X").
11. **Truncation**: any truncated title gets a full-text affordance (tooltip on focus and hover, or wrap at ≤ 2 lines on mobile).
