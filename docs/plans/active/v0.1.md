## Decisions

- 2026-10-22: Kiểm tra Bước 3 bằng trang `/debug` tạm, xóa khi xong Bước 4.
- 2026-10-22: Repo private `Brainrot`; agent tự commit/push/PR/merge sau mỗi bước.
- 2026-10-22: Next.js 16.4 bật sẵn `cacheComponents` → Bước 3 dùng `"use cache"` + `cacheLife`/`cacheTag`
  thay cho `unstable_cache` nếu docs trong `node_modules/next/dist/docs/` xác nhận; kiểm tra trước khi code.
- 2026-10-22: Theme: inline script trong `<head>` đặt `data-theme` (theo guide "preventing flash before hydration" của Next).
- 2026-10-22: Font Inter (sans) + Lora (serif), subset `vietnamese`.
- 2026-10-22: Đăng nhập: cookie `<hạn>.<HMAC>` ký bằng Web Crypto; trang sau đăng nhập nằm trong route group `(app)`.
  Server Action ghi dữ liệu (Bước 5) phải tự kiểm tra cookie, không chỉ dựa vào proxy (docs Next khuyên vậy).
- 2026-10-22: Notion: SDK 5.27 (API 2025-09-03) query theo data source; tra data source ID từ database ID
  trong env (cache "days"). Retry 429 dùng sẵn của SDK (có đọc Retry-After). Cache dữ liệu bằng `"use cache"`
  + `cacheLife` 5 phút + `cacheTag` (tasks/knowledge/daily); Bước 5 dùng `updateTag("tasks")`.
- 2026-10-22: Trang đọc Notion render lúc request: `<Suspense>` + `connection()` (vì "hôm nay" đổi theo
  request); dữ liệu vẫn từ cache 5 phút. Build không cần NOTION_TOKEN.
- 2026-10-22: Logic Today tách thành hàm thuần ở `lib/today.ts`.
- 2026-10-22: Tích xong: `completeTask` tự kiểm tra cookie + định dạng ID; `markTaskDone` chỉ ghi trang có
  parent là database Tasks; `useOptimistic` đổi UI ngay, lỗi thì tự hoàn tác + báo lỗi. Bộ lọc giữ ở state
  phía client (không lưu URL).
- 2026-10-22: Quyết định sản phẩm (3 việc từ Daily Log, màu Lĩnh vực) đã ghi vào `SPEC.md`.
