## Approach

Mỗi bước một nhánh → lint + test + build → ảnh thật 1440×900 hai theme (tài khoản demo) → PR → merge (giữ nhánh).
Migration chỉ thêm cột, Trung áp lên Neon (`npm run db:migrate`) trước khi merge PR dùng cột đó.

## Steps

1. **Migration:** `tasks.top_on`, `goals.parent_id` trong `lib/db/schema.ts`; `npm run db:generate`; Trung chạy
   `db:migrate`, kiểm bảng `drizzle.__drizzle_migrations`.
2. **3 việc hôm nay:** hàm `lib/db/tasks.ts` (gắn / bỏ sao, giới hạn 3, lọc `userId`) + test; action; thẻ "3 việc hôm
   nay" ở Today; ☆ ở "Hôm nay làm" và "Ngày mai làm"; dòng Dashboard. Seed demo có 3 việc gắn sao.
3. **Chia mục tiêu tháng xuống tuần:** hàm `lib/db/goals.ts` (đặt cha, kiểm tháng chạm tuần, lọc `userId`) + test;
   "+ Chia cho tuần…" và chip x/y ở Tháng; ô "Thuộc mục tiêu tháng", dòng "↑", "Đổi mục tiêu tháng" ở Tuần;
   giữ / bỏ cha khi chuyển sang tuần sau. Seed demo có mục tiêu tháng đã chia.
4. **Chốt:** gộp mục 12 vào 5.1 / 5.3 / 5.4 / 3 của `SPEC.md`; README / hướng dẫn; plan → `completed/`.

## Validation

`npm run lint`, `npm test`, `npm run build`; ảnh 1440×900 sáng / tối Today, Goal Tháng, Goal Tuần, Dashboard; Trung test
tay theo danh sách cuối mỗi bước.

- Phình phạm vi sát hạn đồ án: nếu tới 30/11 bước 3 chưa xong thì dừng ở bước 2, ghi lại trong `SPEC.md`.
