## Risks And Recovery

- Lint của Brainrot (eslint, rule React mới) khắt khe hơn oxlint của planner → có thể phải sửa nhiều chỗ nhỏ.
- Tên biến CSS trùng (`--line`, `--accent`) → giới hạn biến planner trong `.planner`.
- `localStorage` → hydration mismatch nếu render phía server → planner chỉ render phía client.
- Rollback: revert PR của bước lỗi.
